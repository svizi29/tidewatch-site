Get Tidewatch for Mac and Windows

Download for MacTidewatch.dmg · 5.2 MB

It needs

  • macOS 14 Sonoma or later
  • Apple Silicon or Intel
  • About 5 MB

On first launch it asks for

  • Full Disk Access optional, to measure everything. It reads sizes only, never your files.
  • Notifications optional, for low-space and fast-growth alerts.

Everything runs on your computer. The Mac app is signed and notarized by Apple.

Tidewatch for Windows

Download for WindowsTidewatch-Setup.exe · 2.8 MB

It needs

  • Windows 10 or 11, 64-bit
  • WebView2, built into Windows 11 (the installer adds it if it's missing)
  • About 3 MB, installed just for you: no admin password

Tidewatch for Windows isn't code-signed yet, so Windows warns you the first time. If Smart App Control is on (some new Windows 11 PCs), it may block unsigned apps entirely.

First time on Windows

Keep the download

Edge or Chrome may say the file isn't commonly downloaded. In Edge: hover the download, click … then Keep, Show more, Keep anyway. In Chrome: click Keep.

Run anyway

Open Tidewatch-Setup.exe. If a blue window says “Windows protected your PC”, click More info, then Run anyway. It names the publisher as “Unknown publisher”: expected until the installer is signed.

Or unblock it first

Right-click Tidewatch-Setup.exe, choose Properties, tick Unblock at the bottom, click OK, then double-click it.

Find it in the tray

Windows 11 tucks new tray icons under ^ in the corner of the taskbar. Drag Tidewatch out to keep it visible. It starts with Windows; switch that off at the bottom of its sidebar.
